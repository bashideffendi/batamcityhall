# Brief 01: Inspirasi & konsep (research/01-inspirasi-konsep.md)

Laporan ini adalah konsep awal. Banyak butirnya sudah ditimpa research/00 dan CLAUDE_CODE_PROMPT. Pakai laporan ini sebagai sumber pola fitur, bukan sebagai spesifikasi nada/visual.

## 1. Harus dibangun
- **Peta sebagai pintu masuk** dengan layer yang bisa dinyalakan (hujan, ombak, CCTV, makan, tukang, kampung tua, feri). Satu skema "tempat" untuk semua layer (`data/places.json`), sehingga "makan dekat tukang yang dituju" dan widget silang gratis. Kriteria: pin klik -> kartu museum; URL per pin dibagikan.
- **Tukang Langganan** (fase 6). Kriteria perilaku:
  - Form wajib: nama tukang, keahlian spesifik, kecamatan, cara menghubungi, kapan terakhir pakai, cerita 1-3 kalimat, tag, kontak perekomendasi (tidak pernah tampil), centang izin.
  - Tampil publik hanya setelah >=2 rekomendasi dari perekomendasi berbeda + moderasi (keputusan 00 menang atas "tampil sebagai Baru direkomendasikan 1 orang").
  - Kartu: jumlah rekomendasi, cerita, tag, area, terakhir dicek, tombol "Masih buka?/Sudah pindah", "Laporkan masalah" (sembunyikan sementara). Tanpa rating bintang.
  - Badge contoh: "Direkomendasikan 3 warga", "Langganan sejak 2010", "Dicek <bulan tahun>", "Bisa dipanggil ke rumah".
  - Filter kecamatan dan kebutuhan; halaman "Tukang Legendaris" (cerita+foto, perlu izin).
  - Label tetap: "Rekomendasi warga, bukan endorsement. Selalu sepakati harga di awal." dan "Tidak ada yang bayar untuk masuk daftar ini. Semua rekomendasi datang dari warga yang pernah pakai jasanya."
  - Seed: pemilik + 10-20 kenalan mengisi 50-100 tukang; jangan rilis kosong. Kampanye bulanan bertema (Bulan Tukang Jahit jelang Lebaran, Bulan Servis AC) dan Duta Kecamatan = ide pasca-rilis (catat TODO).
- **Cerita & Budaya** (fase 5): peta Kampung Tua, Barelang scrollytelling (J1 ke J6), Batam Dulu vs Sekarang (foto + slider tahun, kolom "saya ingat ini"), kamus, "Batam yang hilang", infografis, kalender acara.
- **Info Warga** (fase 3): layanan publik, nomor darurat, panduan "KTP pindahan di Batam" (tulis sendiri, tautkan sumber resmi; data 00 bagian 8: struktur halaman + TODO), harga pangan (lihat pertanyaan).
- **Hari Ini** di beranda: hujan, ombak, feri terakhir, peringatan, gempa terakhir "bila relevan" (autogempa.json, di-cache).
- **Main-main** (fase 9): Vibe Map aman, "Ke Singapura atau Ke Nagoya?" (kalkulator biaya feri vs belanja, data asli), Hujan Bingo, kartu pos. Hanya kategori cuaca/macet/ngopi.

## 2. Spesifikasi eksak
**Sumber data terbuka (URL persis):**
- BMKG prakiraan: `https://api.bmkg.go.id/publik/prakiraan-cuaca?adm4={kode}` (3 hari, per 3 jam, update 2x/hari, kode adm4 kelurahan; Kota Batam `21.71` per 00). Wajib atribusi BMKG.
- BMKG peringatan dini CAP: https://data.bmkg.go.id/peringatan-dini-cuaca/ (sampai kecamatan, poligon).
- BMKG maritim: `https://peta-maritim.bmkg.go.id/public_api/perairan` (GeoJSON wilayah + prakiraan gelombang).
- BMKG gempa: `https://data.bmkg.go.id/DataMKG/TEWS/autogempa.json`, `gempaterkini.json`, `gempadirasakan.json` (repo https://github.com/infoBMKG/data-gempabumi). Batas ~60 request/menit/IP -> cache wajib.
- Bapanas: panelharga.badanpangan.go.id (data harian, cutoff 13.00 WIB; dev: dev-panelharga.badanpangan.go.id/harga-eceran). Tanpa API resmi terdokumentasi; cek ketentuan sebelum scrape; belum terkonfirmasi ada filter Kota Batam.
- Feri: https://singaporecruise.com.sg/schedule/ferries/ (live) + situs operator. Tidak ada API; mulai dari jadwal statis kurasi + penafian.
- Cron/ingest: Vercel Cron atau GitHub Actions (contoh QuakeLog tiap 15 menit).
- Template storymap: https://github.com/digidem/maplibre-storymap, https://github.com/OroraTech/scrolly-maplibre (Scrollama + MapLibre).
**Fakta konteks yang boleh dipakai (bertanggal):**
- Kampung Tua: 37 titik diukur 2019 (Antara Kepri); ~1.600 ha (RKWB, Media Center Batam 2019); 134 total dgn 33 mainland (STPN); sumber lain 33/36. Wajib sebut sumber+tahun, jangan pilih satu angka diam-diam.
- Barelang: 6 jembatan, Juli 1992-Januari 1998 (peresmian 25 Jan 1998 per Wikipedia EN), total bentang ~2 km (Wikipedia ~2,26 km).
- Feri: sejak Juli 2026 semua feri Batam dari HarbourFront berangkat dari Singapore Cruise Centre baru (5 HarbourFront Avenue), sumber batam.com (bukan operator, verifikasi). Rute: HarbourFront-Batam Centre (BatamFast, Sindo, Majestic), HarbourFront-Sekupang, HarbourFront-Harbour Bay (Horizon), Tanah Merah-Batam Centre/Nongsapura. Feri terakhir Batam Centre-HarbourFront ~20:30 WIB. Selalu tampilkan "cek ke operator".
**Pola referensi (angka untuk catatan, bukan UI):** NEONSIGNS.HK >4.000 foto 21 Mar-30 Jun 2014; OldNYC ~50.000 foto; Fortepan didirikan 2010, >200.000 foto; Repair Café 4.045 lokasi; Repair Kopitiam 2.300 barang 2025, 69% berhasil per berat, 10 lokasi, ~300 coach; Front Porch Forum 235.000 dari 270.000 rumah tangga VT, >16.000 bisnis, 48% (klaim FPF sendiri).
**Stack (bagian laporan, versi di prompt menang):** MapLibre GL JS + Protomaps/PMTiles (R2), Maputnik untuk style, Scrollama, D3 / Rough.js / Observable Plot (infografis), Supabase (Postgres+auth+storage foto). Next.js 16 per prompt.
**Roadmap laporan (pemetaan ke fase prompt):** Fase 0 fondasi -> F1; MVP -> F1-F3 + F6; komunitas -> F6; budaya -> F5; main-main -> F9. Urutan prompt bagian 9 menang.

## 3. Aturan & larangan
- Nada: ikut 00 (premium, kalem). Abaikan "lucu", maskot, tulisan tangan playful, "Ape kabar, Batam?" sebagai gaya utama.
- Humor hanya soal cuaca/macet/makanan; tidak pernah soal kelompok orang. Vibe Map: tanpa kategori etnis/kelas; label crowdsourced wajib dimoderasi (pelajaran Hoodmaps).
- Kampung Tua: nada budaya/sejarah, netral soal sengketa lahan/UWTO; jangan tampilkan batas, luas, status lahan.
- Nomor HP tukang/perekomendasi = data pribadi (UU PDP): hanya dengan izin; nomor perekomendasi tidak pernah ke klien.
- Ombak "Aman nyebrang ke Pulau Abang/Galang?": wajib penafian bukan pengganti info syahbandar.
- Atribusi BMKG dan OSM di setiap layer terkait.
- Jangan scrape Bapanas tanpa cek ketentuan.

- **Sponsor lokal / listing "Unggulan" / iklan lokal / merch bayar** (laporan 01) vs 00 + prompt bagian 2: TANPA iklan, listing berbayar, sponsor di direktori. Menang 00. Yang tersisa: donasi (Saweria/Trakteer; KaryaKarsa disebut laporan, URL dari pemilik), merch opsional (tanya pemilik), hibah.
