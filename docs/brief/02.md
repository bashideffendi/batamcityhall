# Brief 02: Teknik mural & peta (research/02-teknik-mural-peta.md)

Sumber utama fase 1 (peta chart, kontur) dan fase 8 (mural). Salinan kode ada di `data/snippets/02-teknik-mural-peta/1..6`; snippet itu ilustrasi (helper `nowInZone`, `clamp`, `pointAlongPolyline` tidak didefinisikan, `gcps` tidak didefinisikan), bukan kode siap jalan.

## 1. Harus dibangun
**Fase 1, Mode Peta (chart laut):** MapLibre + PMTiles Batam, style `day` dan `night` (dua JSON, atau `setPaintProperty`), glyph serif self-host, graticule + label derajat-menit di tepi, tekstur kertas lewat overlay CSS, arsiran pantai, kontur kedalaman GEBCO, 20-40 sketsa landmark sebagai `symbol` layer, kartu museum, URL per pin + OG image. Kriteria: layer bisa on/off; HP menengah lancar; label kontur "kedalaman indikatif, bukan untuk navigasi".
**Fase 8, Mode Mural:**
- `/mural/[segment]` memakai OpenSeadragon + tile DZI + SATU `<canvas>` overlay (jangan canvas per efek, satu loop rAF).
- Tool GCP internal (micro-app Vite): MapLibre kiri + OSD kanan, klik pasangan titik, simpan `data/mural/segNN.gcps.json`.
- Hotspot poligon -> kartu museum (`<dialog>`), daftar hotspot `<button>` di DOM, strip navigasi `<nav>` 8 perhentian (1 aktif, sisanya "segera"), quest + badge "Cari! n/N" (aria-live polite) + mode petunjuk, link `?spot=<id>` + OG image per spot.
- Overlay hidup berurutan: siang/senja/malam (suncalc) -> layer lampu malam -> hujan per poligon -> ombak -> feri dari jadwal. Tombol "Gerak: hidup / tenang" + `prefers-reduced-motion`.
- Halaman "Cara mural ini dibuat" (bagian tangan vs AI).
- Kriteria: satu segmen penuh dengan placeholder berlabel "ilustrasi sementara" dan data hidup.
Rekomendasi segmen pertama: Barelang 1-6 (quest jelas, ombak paling terasa) atau Harbour Bay-Nagoya (padat hotspot); pilihan dibawa ke pemilik.

## 2. Spesifikasi eksak
**Library & versi disebut:** `openseadragon` 6.1.1 (~88 kB min+gzip), `maplibre-gl`, `pmtiles`, `@protomaps/basemaps`, `@allmaps/transform` (TPS), `suncalc`, `d3-delaunay` (opsi), ThinPlateSplineJS (MIT, alternatif), PixiJS v8 (~258 kB, hanya bila butuh shader), Annotorious `annotorious-v2-openseadragon` (BSD-3, editor internal saja), `next/og`. Leaflet 1.9 ~40 kB (opsi cadangan; 2.0 beta rilis 2 Nov 2026). Next.js: `dynamic(() => import(...), { ssr:false })` untuk mural/peta.
**Tile:**
```
vips dzsave batam_mural_seg01.tif public/tiles/seg01 --tile-size 512 --overlap 1 --suffix .webp[Q=82]
vips dzsave seg01.tif out_xyz --layout google --suffix .webp[Q=82] --background 244,239,228
vips dzsave seg01.tif seg01.zip
gdal2tiles.py --xyz -p raster -z 0-6 -w none seg01.png tiles/
rclone copy public/tiles r2:batam-mural/tiles --transfers 32
rclone copyto file.pmtiles r2:bucket/file.pmtiles
```
Layer `skip_blanks` default 5. WebP 512 px Q 75-82; muatan awal <1,5 MB. Aktifkan CORS bucket. Jangan taruh tile di `public/` Vercel produksi.
**R2:** $0,015/GB-bulan; Class A $4,50/juta; Class B $0,36/juta; gratis 10 GB, 1 juta A, 10 juta B per bulan; egress gratis; pasang domain kustom + cache CDN (contoh `tiles.batamcityhall.id`).
**TPS:**
```ts
type GCP = { resource: [number, number]; geo: [number, number]; label?: string };
import { GcpTransformer } from '@allmaps/transform';
const t = new GcpTransformer(gcps, 'thinPlateSpline');
const px = t.transformBackward([104.0305, 1.1450]); // lng,lat -> piksel
const geo = t.transformForward([12345, 6789]);      // piksel -> lng,lat
```
30-80 GCP/segmen; leave-one-out; target <40 px zoom penuh (asumsi). Poligon hujan: densify tiap ~200 m sebelum transform; hitung di Route Handler dengan cache, kirim piksel. Feri: polyline piksel + fraksi waktu, bukan transform titik-per-titik.
**Feri:**
```ts
const now = nowInZone('Asia/Jakarta'); // WIB UTC+7
const f = clamp((now - depart) / duration, 0, 1);
const [x, y, angle] = pointAlongPolyline(routePx, f);
```
Label "posisi perkiraan berdasar jadwal". Data jadwal dari `data/feri/` (bukan Sheets). Contoh jadwal: `{ route:'batamcentre-harbourfront', depart:'08:00', durationMin:60 }`.
**Hujan Canvas2D:** `ctx.save(); beginPath(path poligon layar); clip();` garis hujan pendek (bukan sprite); partikel ~ luas layar x mm/jam, batas keras ~600 di HP; riso: garis 1 px biru, `globalCompositeOperation='multiply'`; kabut = halftone/grain semi-transparan.
**Ombak:** mask air PNG 1-bit/segmen; garis "~" digeser sin(t); amplitudo+kecepatan = f(Hs hujandibatam); Hs <0,5 m tenang (gerak 1 px, lambat); >1,5 m busa putih; WebGL: render 0,5x DPR.
**Siang/senja/malam:** fase dari posisi matahari `suncalc` lat 1,1 lng 104,0. Teknik: (1) CSS overlay `mix-blend-mode: multiply` gradien (senja oranye-merah muda, malam biru tua 60%); (2) layer lampu DZI kedua via `viewer.addTiledImage`, fade opacity, blend screen/lighter; (3) LUT WebGL ditunda. Malam = tinta biru gelap + kuning fluoro.
**Performa/aksesibilitas:** 30 fps efek, 15-20 idle; DPR canvas maks 1,5; hentikan loop saat `document.visibilityState` hidden dan IntersectionObserver; hit-area min 44x44 CSS px (zoom-out diperbesar), poligon terkecil menang; reduced-motion: hujan arsiran statis, ombak berhenti, kapal melompat tiap 1 menit, tanpa transisi zoom. `const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;`
**Skema hotspot** (`data/raw/02-teknik-mural-peta__1.json`, bentuk contoh; nilai contoh BUKAN data):
`{id, segment:"seg02", shape:{type:"polygon",points:[[x,y]...]}, geo:[lng,lat], kind:["kampung-tua"], title:{id,en}, museumLabel:{year,material,body}, quests:["temukan-8-kampung-tua"], source:"wajib"}`. Atau W3C Web Annotation. Progres quest di `localStorage`.
**Chart Batam (laporan):**
```
pmtiles extract https://build.protomaps.com/YYYYMMDD.pmtiles batam.pmtiles --bbox=103.6,0.6,104.3,1.35 --maxzoom=15
```
Warna laporan darat `#F3EBDD`, laut siang `#DCE6E4`, laut malam `#0E1A24` -> lihat Konflik. Arsiran pantai: `line-offset` -2, -5, -9 px, opacity menurun. Label: `text-transform: uppercase`, `text-letter-spacing: 0.15`, `text-font: ["Cormorant SC Regular"]` (laporan; font final 05). Graticule tiap 1' atau 5' (GeoJSON line tipis) + label React dari `map.getBounds()`, contoh "1°08′N, 104°00′E". Paper overlay: `<div>` `background-image:url(paper.webp)` `mix-blend-mode:multiply` `pointer-events:none`. Lampu pelabuhan: `circle-blur` kuning. Sketsa landmark: SVG -> sprite atau `map.addImage` SDF.
**Kontur GEBCO (urutan):**
```
gdalwarp -te 103.5 0.5 104.5 1.5 -r cubic -tr 0.001 0.001 gebco.tif batam_bathy.tif
gdal_contour -a depth -fl -2 -5 -10 -20 -30 -50 -100 batam_bathy.tif contours.geojson
gdal_contour -p -amin dmin -amax dmax -fl -200 -100 -50 -30 -20 -10 -5 -2 0 batam_bathy.tif depth_areas.geojson
ogr2ogr -clipsrc water_polygons_batam.shp contours_sea.geojson contours.geojson
tippecanoe -o bathy.pmtiles -Z6 -z14 -l contours --simplification=4 contours_sea.geojson
# gabung: tippecanoe -o bathy.pmtiles -L contours:contours_sea.geojson -L depth:depth_areas.geojson
```
Smoothing ala NOAA: `gdalwarp -r cubic` + `ogr2ogr -simplify 0.0005`. GEBCO_2025 grid 15 arc-second (~450 m, SRTM15+ v2.7); pakai rilis terbaru (GEBCO_2026 ada) dan sebut versi. Data kecil boleh GeoJSON source. Perhatikan: nama file input placeholder, `-te` memakai bbox 103.5 0.5 104.5 1.5.
**Struktur folder usulan:** `/app/(site)`, `/app/peta`, `/app/mural/[segment]/page.tsx`, `/app/api/{rain,ferry}/route.ts`, `/app/api/og/[spot]/route.tsx`, `/components/map/{MapView,layers/*,Graticule}`, `/components/mural/{MuralViewer,OverlayCanvas,effects/{rain,waves,ferry,daylight},HotspotLayer,MuseumCard,QuestBadge,StopStrip}`, `/lib/{geo/tps,geo/densify,time/batam,data/*}`, `/data/mural/{segments,segNN.gcps,segNN.hotspots,segNN.water-mask.png}`, `quests.json`, `ferry/routes.px.json`, `map/style.{day,night}.json`, `/scripts/{tile-segment.sh,bathy.sh,gcp-tool/}`.

## 3. Aturan & larangan
- Posisi feri = simulasi dari jadwal; label wajib. Jangan terkesan AIS.
- Kontur laut: "kedalaman indikatif, bukan untuk navigasi".
- Laut jangan digenerate AI; render prosedural. AI hanya isian latar dan diumumkan terbuka; output murni AI tak dilindungi hak cipta (US Copyright Office, Jan 2025); hukum Indonesia belum diriset.
- Tidak ada quest/poin di titik memorial/konflik (00 9.3; lihat brief 03).
- Placeholder wajib berlabel "ilustrasi sementara".
- Jangan bikin canvas per efek; jangan tile besar di `public/`.
- Jangan sentuh/bangun ulang API cuaca; pakai data hujandibatam yang dilebur (fase 2).

## 5. Konflik
- **Bbox ekstrak:** laporan `103.6,0.6,104.3,1.35`; 00 usul `103.55,0.45,104.75,1.5`; prompt menyuruh ikut 00. Menang 00. Bbox laporan sebenarnya sudah menutup semua landmark laporan 03 (lat 0.73-1.19, lng 103.89-104.22) tetapi memotong siluet Singapura (utara lat 1.35) dan Bintan (timur 104.3); itu alasan 00 lebih lebar. Konfirmasi saat ekstrak.
- **Warna chart:** laporan `#F3EBDD`/`#DCE6E4`/`#0E1A24` vs token 05 (`--bch-map-land #F4EFE4`, `--bch-map-water #DCE3E1`, malam darat `#16263A`, laut `#0F1B2A`). Menang `data/design/` (05).
- **Font label:** Cormorant SC/EB Garamond SC/Libre Caslon vs pilihan 05 (Source Serif 4, Plus Jakarta Sans, IBM Plex Mono). Menang 05; glyph PBF dibuat dari font terpilih.
- **Data feri Google Sheets** vs data statis `data/feri/`. Menang prompt/data repo.
- **Data konten Sheets/Supabase** vs prompt: JSON statis + zod, Supabase hanya kiriman warga.
- Laporan menyebut Leaflet sebagai opsi; prompt memakai MapLibre (menang). Hidden-object "Cari!" tidak boleh menyentuh topik sensitif.
