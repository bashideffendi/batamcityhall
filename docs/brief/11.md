## 1. Harus dibangun
1. **Layer batas wilayah tipis** (kecamatan + kelurahan) di peta (prompt 5.6): hanya garis tipis, bukan klaim resmi; sumber dan edisi tampil di atribusi peta. File TERPISAH per sumber/lisensi (mis. `admin_big.pmtiles`/`admin_cod.pmtiles`), jangan digabung ke tabel POI turunan OSM. `attribution` per source di MapLibre.
2. **Pipeline batas** (skrip di `tools/`, hasil + tanggal tarik di `data/osm/` atau `data/wilayah/`): tarik → bandingkan → pilih satu canonical → normalisasi → PMTiles. Langkah (dari Recommendations 1,2,8):
   - Tarik COD-AB Indonesia (HDX), BIG `Administrasi_AR_KelDesa_10K`/`BATAS_DESAKEL_AR`, dan (opsional, lihat Aturan) BP Batam `/27`. Bandingkan di QGIS: jumlah kelurahan (acuan lokal `data/wilayah/kelurahan.json`: **12 kecamatan, 64 kelurahan**), nama, kode `kdebps`/Kemendagri (kode lokal `21.71.xx`), cakupan pulau. Canonical saran: COD-AB atau BIG; sisanya hanya QA.
   - Normalisasi: `ogr2ogr -f GeoJSON -t_srs EPSG:4326 -lco RFC7946=YES -lco COORDINATE_PRECISION=6 out.geojson in.geojson`; sederhanakan `mapshaper in.geojson -simplify 15% keep-shapes -o out.geojson`; atribut seragam `kode_kel, nama_kel, kode_kec, nama_kec, sumber, edisi`.
   - PMTiles: `tippecanoe -o admin_batam.pmtiles -zg --drop-densest-as-needed -l kelurahan kelurahan.geojson -l kecamatan kecamatan.geojson` (tippecanoe ≥2.17). Pisahkan per sumber/lisensi: `osm_*.pmtiles`, `admin_big.pmtiles`, `halte_warga.pmtiles`.
   - QA visual wajib untuk Belakang Padang, Bulang, Galang (BIG mengaku ada "area tidak terdefinisi" untuk pulau/kepulauan dan desa pemekaran belum masuk). Bila bolong, catat di `docs/DATA_DECISIONS.md`.
3. **`docs/DATA_SOURCES.md`** (laporan Rec. 9): URL endpoint, tanggal tarik, edisi, lisensi atau "tidak dinyatakan", teks atribusi. Format tabel dari `geoportal.json` (44 entri) + `endpoint.json` (98 entri). Sertakan juga draf surat izin ke BIG (`info@big.go.id`), PPID BP Batam, Disperkimtan (`info@hangjebat.go.id`, (0778) 8014473); simpan balasan di repo.
4. **Join spasial koordinat kosong ke OSM, bukan ke POI pemerintah** (Rec. 3): tarik dari OSM `amenity=school|hospital|clinic|place_of_worship|townhall`, `landuse=cemetery`, `leisure=park|pitch`, `amenity=ferry_terminal`, `highway=bus_stop`; hasil hanya untuk memvalidasi/mengisi `status_koordinat` (jalur data kurasi + `koordinat_user.json`), dicatat bertanggal di `data/osm/`. POI BP Batam (`WEBGIS_TEMATIK_MOBILE_POI_`) dan layer HANG JEBAT hanya "daftar periksa": bila ada di sana tapi tidak di OSM → verifikasi survei/citra lalu petakan sendiri di OSM.
5. **Kontur kedalaman** (Rec. 7, tumpang tindih laporan 02): garis pantai dari OSM/Protomaps; kontur dari BATNAS (Ina-Geoportal, perlu login pemilik) → `gdal_contour -i 5` → layer terpisah atribusi BIG; label "kedalaman indikatif, bukan untuk navigasi". Garis batas perairan desa BP Batam `/MapServer/26` (`kelas`=16) hanya hiasan referensi.
6. **Halte Trans Batam** (Rec. 4): skema `halte.geojson` (`id, nama, koridor[], sumber, tanggal_verifikasi`) tetap mengikuti `data/trans_batam/halte.json` (lihat brief 10); `highway=bus_stop` OSM dipakai mencocokkan, survei warga melengkapi.
7. **Kampung Tua** (Rec. 5, ke F5): tidak ada data spasial terbuka; daftar nama dari Satu Data Batam; titik via OSM `place=village|hamlet`; tandai `status_verifikasi`. Jangan menampilkan batas/luas/status lahan (prompt 4.6).
8. **Rawan bencana** (Rec. 6): layer HANG JEBAT hanya referensi visual; layer yang boleh tampil = BNPB/InaRISK `inarisk1.bnpb.go.id:6443/arcgis/rest/services` sebagai layer terpisah ber-atribusi (lisensi tidak jelas; tunda sampai dicek).
9. **Halaman admin "Data yang perlu dicek ulang"** memuat entri bersumber geoportal berstatus `perlu_cek_ulang`.

## 2. Spesifikasi eksak
**Boleh dipakai (atribusi, layer terpisah)**
- BIG `https://geoservices.big.go.id/rbi/rest/services/BATASWILAYAH/Administrasi_AR_KelDesa_10K/MapServer/0` — 1:10.000, edisi Okt 2020 (publikasi 23-10-2020), EPSG:4326, field `WADMKC`,`WADMKD` (+`WADMKK` untuk filter 'Kota Batam', cek nama field lewat `/0?f=pjson`), `maxRecordCount` 4000, kapabilitas `Map,Query,Data`, `exportTilesAllowed:false`, copyright "Badan Informasi Geospasial". Extent nasional 94,97–141,02 BT, difilter bbox Batam.
- BIG `.../BATASWILAYAH/BATAS_DESAKEL_AR/MapServer/0` (edisi mungkin lebih baru, cek `/info/iteminfo`; max 1000, HasZ), `.../Administrasi_AR_Kecamatan_10K/MapServer`, `.../BATAS_KECAMATAN_AR/MapServer`, `.../Administrasi_AR_KabKota_50K/MapServer` (Sep 2023), `.../Administrasi_LN_KabKota_50K/MapServer/info/iteminfo` (2022), `.../BATAS_WILAYAH/MapServer/10` (garis kecamatan) dan `/13` (area kab/kota).
- BP Batam (ArcGIS 10.51, `https://web-gis.bpbatam.go.id/arcgis/rest/services`): `PROYGISPUSREN21_EKSTERNAL/PETA_ADMINISTRASI_BATAM/MapServer` (0 Toponim Ibukota, 1 Adm Kota Batam, 2 Kecamatan, 3 Kab/Kota; EPSG:4326, max 2000); `WEBGIS_TEMATIK/WEBGIS_TEMATIK_MOBILE_BASEMAP/MapServer/27` (kelurahan; `kdepum`,`namobj`,`kdebps`; EPSG:3857; max 2000; minScale 1:100.000) dan `/26` (garis batas).
- Pembanding berlisensi jelas: COD-AB Indonesia `https://data.humdata.org/dataset/cod-ab-idn` (BPS via OCHA/HDX, level 0–4, basis 2020), **CC BY 3.0 IGO** — dikutip dari mirror GitHub `klikpeta-tech/id-kecamatan-geo`; teks lisensi di halaman HDX sendiri BELUM terlihat langsung → verifikasi sebelum bergantung.
- BPS Wilkerstat (lisensi tidak dinyatakan): `https://geoportal.bps.go.id/server/rest/services/wilkerstat/desa/MapServer/0` (juga `/kecamatan`,`/kabupaten`,`/provinsi`), SLS `.../Hosted/Wilkerstat_Publish_Tile_Full/MapServer/4` (field `nmkec`,`nmdesa`,`kode_sls4`; max 1000). Hanya pembanding.
- Query GeoJSON (pola persis dari laporan, `snippets/11-geoportal/4.txt`): `curl -G "<layer>/query" --data-urlencode "where=1=1" --data-urlencode "outFields=*" --data-urlencode "outSR=4326" --data-urlencode "f=geojson"`; BIG tambahan `geometry=103.5,0.25,104.5,1.21 geometryType=esriGeometryEnvelope inSR=4326 spatialRel=esriSpatialRelIntersects resultOffset=0 resultRecordCount=1000` (paging; bbox ikut menangkap Bintan/Karimun → filter setelahnya). Alternatif paging otomatis: `pip install esridump`; `esri2geojson "<URL layer>" out.geojson`.

## 3. Aturan & larangan
- TIDAK ada lisensi terbuka eksplisit untuk BIG/BP Batam/HANG JEBAT: tampilkan sebagai layer terpisah dengan atribusi; **jangan impor ke OSM**; jangan gabung ke basis data turunan OSM; kata "Produced Work" ODbL = interpretasi umum, bukan nasihat hukum (tulis begitu di DATA_SOURCES). Risiko residual: tidak ada jaminan tertulis.
- **GADM dilarang** (redistribusi/komersial tanpa izin). **geoBoundaries** (ODbL, hanya ADM0–ADM2) tidak cukup untuk kelurahan.
- Jangan menyentuh `data_terbatas`, `data_tertutup`, `DATACAKRA/Data_Tertutup`; jangan memakai token service (`.../sharing/rest/generateToken`); jangan mempublikasikan Bidang Tanah Fisik atau `PETA_INFRASTRUKTUR` (INTERNAL).
- BP Batam `robots.txt` menolak crawler otomatis, Ina-Geoportal memblokir bot: default **tidak ada tarikan otomatis dari BP Batam**; kalau dilakukan, sekali tarik, rate limit rendah, skrip pribadi, simpan lokal + tanggal. Jangan scrape massal endpoint internal HANG JEBAT.
- Jangan klaim 13.594 dataset BP Batam sebagai jumlah layer publik (klaim beranda); jangan menyebut data HANG JEBAT mencakup seluruh Batam.
- Endpoint ArcGIS bisa berubah/ditutup: simpan salinan lokal + tanggal tarik.
- Status per butir: "Terverifikasi" / "Perlu dicek" (termcondition Ina-Geoportal, folder POI/Perindustrian/KEK, XHR HANG JEBAT, edisi BATAS_DESAKEL_AR) / "Asumsi" (isi POI BP Batam, kampung tua di folder Pertanahan, Produced Work); pertahankan tiga tingkat di DATA_SOURCES.
- Batas hanya "layer tipis, bukan klaim resmi". Jangan menampilkan batas/luas Kampung Tua.

## 5. Konflik
- **Batas kecamatan**: prompt 4.0 butir 8 menyuruh memakai ulang `data/kecamatan-kepri.geojson` (BIG edisi Juni 2026, repo hujandibatam, "cek dan catat lisensi/atribusi"); laporan 11 merekomendasikan COD-AB (BPS/OCHA, 2020) atau BIG sebagai canonical dan menyebut BIG/BP Batam tanpa lisensi terbuka, serta BIG KelDesa_10K berstatus edisi Okt 2020. Putusan: kecamatan = pakai file hujandibatam (paritas dengan peta hujan per kecamatan), dicatat edisi + atribusi BIG; kelurahan = canonical per perbandingan QGIS (COD-AB atau BIG) dengan catatan lisensi; catat di `docs/DATA_DECISIONS.md`. Satu sumber untuk "hujan per kecamatan" dan layer batas supaya garis sejajar.
- **Jumlah kelurahan**: `kelurahan.json` 64 vs HANG JEBAT 39 (9 kecamatan): HANG JEBAT bukan acuan.
- **Kampung Tua 37 vs 24**: lihat Spesifikasi; sejalan dengan laporan 04 untuk daftar kampung tua; hasil resmi menunggu Dinas Pertanahan.
- Laporan 11 menyebut target "11 koridor" (K10 Tembesi–Barelang, K11 Nongsa–Jodoh) dan Kepala UPT "Sucipto"; laporan 10 menyebut 10 koridor dan "Bambang Cipto" (lihat brief 10). Jangan tampilkan K11 atau nama pejabat.
- `places.json` memuat 5 `halte-trans-batam-*` dari laporan 11 (kemungkinan duplikat halte di `halte.json`, namespace berbeda) → dedup via `tools/merge_aliases.json` atau biarkan keduanya dengan catatan.
- Prompt 4.4/4.0 mengizinkan batas BIG dengan atribusi; laporan 11 menegaskan "tidak ada jaminan tertulis". Menang laporan 11 untuk wording risiko (ditulis di Kolofon sebagai "digunakan dengan atribusi; izin sedang diminta").
