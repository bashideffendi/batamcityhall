Sumber: research/05-panduan-gaya.md (812 baris, dibaca penuh). Tanda [V]=terverifikasi laporan, [A]=usulan/asumsi laporan (boleh disesuaikan, catat di PLAN.md). ## 1. Harus dibangun
- **Sistem token** (F1): impor data/design/design_tokens.css apa adanya; mode malam lewat `:root[data-theme="night"]`; ikuti `prefers-color-scheme` kecuali `data-theme="day"`; toggle siang/malam di strip navigasi (ikon bulan sabit garis). Tailwind 4 dipetakan ke token yang sama.
- **Font** (F1): Source Serif 4 (judul, kicker small caps, angka), Plus Jakarta Sans (isi), IBM Plex Mono (data). Self-host, subset Latin, WOFF2. Glyph PBF untuk MapLibre dibuat dari instance statis (lihat bagian 2).
- **Peta chart laut** (F1): style siang dan "chart malam" dengan tabel layer di bagian 2; kartusis, mawar angin 8 titik minimal, skala batang (km + nautical mile), graticule tepi per 1′, garis 1°N beraksen berlabel "1°00′ U", waterlining (2-3 garis `line-offset`), garis kedalaman putus halus, label hierarki lama (laut italic, pulau kapital, kampung roman). Pola arsir bakau/hutan dari sprite `fill-pattern`.
- **Komponen** (F1/F3): kartu label museum, strip navigasi 44 px, menu HP "daftar isi majalah", tombol layer berupa legenda chart, halaman Loket (nomor raksasa), blok "Kolofon Loket", blok kredit Code/Data/Design/Illustration di akhir cerita.
- **Tekstur** (F1): grain tile statis, bukan filter live. Reduced motion/data mematikan efek.
- **Logo** (F1): wordmark arsip, emblem stempel bulat, monogram BCH untuk favicon (lihat bagian 2). Footer disclaimer di semua halaman.
- **Kolofon** (F1): atribusi peta lama (NLB, KITLV/Leiden), font + lisensi, hex Riso "perkiraan", sumber tekstur CC0, keterbukaan soal AI bila dipakai; token dirilis terbuka (semangat Cooper Hewitt).
- **Microcopy** (F1): 8 contoh pola jadi dasar string ID/EN (data/design/microcopy.json); itik berbaris sebagai ikon loading.
- **Ornamen Melayu** (F1/F5): pucuk rebung (pembatas), awan larat (sudut kartu), itik pulang petang (loading, Loket 03), selembayung (ikon tentang), tiang pelantar (pembatas). Hanya garis.
- **Aksen Jawi** (F9, opsional): nama Loket Jawi kecil di bawah judul Latin, HANYA setelah dicek penutur/ahli.

### Spasi, garis, radius, bayangan, gerak, tekstur (token)
Spasi basis 4: 4,8,12,16,24,32,48,64,96,128 px; gutter `clamp(1rem,0.5rem + 2vw,2rem)`. Stroke hair 0.5, fine 0.75, base 1, icon 1.25 px. Radius 0 / 2 / 4 px, pill 999 hanya chip status. Shadow siang paper `0 1px 0 rgba(28,27,25,.06), 0 2px 6px -2px rgba(28,27,25,.08)`, lift `0 8px 24px -12px rgba(28,27,25,.18)`; malam paper `0 1px 0 rgba(0,0,0,.3)`, lift `0 8px 24px -12px rgba(0,0,0,.5)`.
Gerak: ease `cubic-bezier(0.2,0,0,1)`, ease-in-out `cubic-bezier(0.4,0,0.2,1)`; durasi instant 120, fast 240, base 420, slow 700, map 1600 ms; shift 8 px; fade+translate 8 px 240-420 ms; flyTo `speed 0.6, curve 1.2`. Reduced motion: fast/base/slow/map = 0ms, shift 0. Tanpa spring/bounce/parallax berat/kursor kustom.
Tekstur: grain `/tex/grain-256.webp` 256x256 <15 KB, `body::before{position:fixed;inset:0;pointer-events:none;opacity:.06;mix-blend-mode:multiply}`; malam `/tex/grain-256-light.webp` opacity .05 `screen`. Serat kertas tile 512 px dari scan CC0 (publicdomainpictures "Paper texture" 1280x900, atau rawpixel CC0), didesaturasi + high-pass + dikompres. Riso offset x 0.6px y -0.4px statis (multiply, layer warna kedua). Halftone di aset, UI kecil `radial-gradient` 4px 4px. Tidak ada grain di atas canvas MapLibre. `prefers-reduced-data`/saveData: tanpa tekstur. Uji CPU 4x + HP kelas Redmi Note.

### Ikon & ilustrasi

## 3. Aturan & larangan
- Fakta dulu, lelucon maks satu klausa yang bisa dihapus tanpa merusak informasi. Kering, jujur soal ketidakpastian.
- Hindari: tanda seru berderet, kapital teriak, emoji di judul; "surga tersembunyi/wajib dikunjungi/hits/instagramable/kekinian/healing"; "dalam rangka/guna/sehubungan dengan/dihimbau"; lelucon merendahkan pendatang, Orang Laut, buruh pabrik, Singapura; bahasa campur paksaan; bercanda saat peringatan cuaca/kecelakaan laut/banjir aktif.
- Desain: tanpa feTurbulence live, grain animasi, backdrop-filter di atas peta, gradasi emas, ornamen Melayu penuh warna sebagai wallpaper, font Arab-Melayu dekoratif, tekstur Rumsey/blog, bounce/spring, parallax berat, kursor kustom, status hanya warna.
- Motif: maknanya hanya dari materi pelajar; verifikasi LAM Kepri/Tenas Effendy sebelum teks publik. Tahun Rusydiah Klub tulis "akhir abad ke-19".
- Jangan cantumkan handle Urban Sketchers Batam (tidak ada). Jangan pakai merek di papan nama ilustrasi ruko.
